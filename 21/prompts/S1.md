# S1.a — print inorder

## Prompt 1

Follow skills/scheme-dev/SKILL.md and read S1.a in the attached assignment. Write only my-append for code/21_q3.rkt using #lang racket/base. It should take two lists and return their concatenation, preserving the order of elements. Use recursion with cons, car, cdr and null?, without using the forbidden built-in append. Include a short comment explaining the base case and recursive step. Do not implement tree traversal yet.

## Prompt 2

Follow skills/scheme-dev/SKILL.md. Using the existing my-append helper in code/21_q3.rkt, write only my-inorder(tree) for S1.a. The tree is either '() or a three-element list (value left right). Return a flat list of values in left-root-right order. The empty tree must return '(). Use only the allowed Scheme built-ins, preserve the existing definitions and include a short comment explaining the recursion. Do not print anything or implement print-inorder yet.

## Prompt 3

Follow skills/scheme-dev/SKILL.md. Using the existing my-inorder helper in code/21_q3.rkt, write only print-inorder for S1.a. It should take one tree, display the inorder traversal as a Scheme list and print exactly one newline. For an empty tree, it must print (). Preserve the existing helper definitions. Do not add headings, top-level function calls or any functions for S1.b or S1.c.

## Prompt 4

Follow skills/scheme-dev/SKILL.md. Write only tests/s1_test.rkt for the existing S1.a implementation in code/21_q3.rkt. Test the balanced tree t1, right-skewed tree t2, symbol tree t3 and empty tree from the assignment, along with a single-node tree, a left-skewed tree and an asymmetric tree. Verify the exact inorder values and output formatting, including the final newline. Do not modify the solution file. Include the command to run the tests from the repository root.
